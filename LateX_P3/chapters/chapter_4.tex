This chapter describes the system end to end: the data, the three encoders, the fusion methods, the coherence analysis, the evaluation protocols, and how the computation was organised. Values stated here are those in the code that produced the results.

\section{Pipeline Overview}
The system is built as three stages, each of which writes its outputs to persistent storage before the next begins, so that an interrupted session can resume where it stopped.

\begin{enumerate}
    \item \textbf{Stage A---encoders.} One model per modality is trained: AST for audio, a facial-emotion ViT for video, EEGNet for EEG.
    \item \textbf{Stage B---features.} Each trained encoder, with its classification layer removed, converts every trial into one feature vector; its class logits are stored alongside.
    \item \textbf{Stage C---fusion.} Fusion methods are trained and scored on the cached features and logits, which makes them cheap to rerun.
\end{enumerate}

Two properties of the fusion module were fixed at the design stage (Figure~\ref{fig:trimodal_pipeline}). It returns, besides its logits, the post-attention embedding of each modality and the fused embedding, so that a temporal model could later be attached without changing it. And it accepts an all-zero EEG input and still produces finite predictions, which is what makes EEG-free inference possible (Section~\ref{sec:modality_dropout}).

\section{Data}
\label{sec:split_alignment}

EAV \cite{Lee2024EAV} contains 42 healthy adults engaged in a cue-based conversation designed to elicit five emotions: Neutral, Anger, Happiness, Sadness and Calmness. EEG was recorded from 30 electrodes at 500 Hz, and audio and 30-frame-per-second video were recorded while the participant spoke. Each participant has 200 interactions, half in which they listen to an emotional prompt and half in which they respond. The released EEG is taken from the listening interactions and the audio and video from the speaking interactions, so the EEG and audio-visual windows of a ``trial'' are not simultaneous (Section~\ref{sec:listenspeak_asymmetry}).

The EAV repository's scripts turn each 20-second interaction into four five-second trials, giving 400 trials per participant and modality, 80 per class:
\begin{itemize}
    \item \textbf{EEG} is downsampled from 500 to 100 Hz by polyphase resampling, band-pass filtered between 0.5 and 45 Hz with a fifth-order Butterworth filter, and cut into windows of 30 channels by 500 samples.
    \item \textbf{Audio} is resampled to 16 kHz and cut into 80{,}000-sample segments; the AST feature extractor turns each into a 128-band log-mel representation when it is loaded.
    \item \textbf{Video} is sampled every sixth frame over the first 600 frames (5 frames per second) and split into four clips of 25 frames, each resized to $224\times224$ pixels and normalised by the ViT's image processor.
\end{itemize}

For the within-subject protocol, the repository's class-stratified split puts 56 trials per class (280) in training and 24 per class (120) in testing. Before the coherence analysis, the three modalities were checked to contain the same number of trials of each class for every participant, which they do. That check is necessary for trial-by-trial comparison but not sufficient; the stronger check of Section~\ref{sec:audit_alignment} shows that trial correspondence within a class cannot be established from the released files. Table~\ref{tab:eav_dataset_structure} summarises the data.

\section{Encoders}

\textbf{Audio: AST.} The Audio Spectrogram Transformer \cite{Gong2021AST} cuts the log-mel spectrogram into overlapping $16\times16$ patches (stride 10), embeds each as a 768-dimensional token, and passes the sequence through a 12-layer, 12-head transformer. The checkpoint \texttt{MIT/ast-finetuned-audioset-10-10-0.4593} (about 87 million parameters, pre-trained on AudioSet) is loaded with a new five-class output layer. The audio feature is the mean of the final-layer token embeddings (768 dimensions).

\textbf{Vision: ViT.} The Vision Transformer \cite{Dosovitskiy2021ViT} cuts each frame into $16\times16$ patches and processes them with a 12-layer, 12-head transformer. The checkpoint \texttt{dima806/facial\_emotions\_image\_detection}, a ViT-base model (about 86 million parameters) trained for seven facial-emotion classes, is reloaded with a five-class output layer; loading through \texttt{from\_pretrained(num\_labels=5, ignore\_mismatched\_sizes=True)} also updates the model's configuration, which the original EAV trainer failed to do (Chapter~\ref{chap:engineering_challenges}). Each frame's classification-token embedding is computed, and the 25 frame embeddings of a clip are averaged into one 768-dimensional feature.

\textbf{EEG: EEGNet.} EEGNet \cite{Lawhern2018EEGNet} is configured with $F_1 = 8$ temporal filters of length 300 samples (three seconds at 100 Hz), depth multiplier $D = 8$ for the depth-wise spatial convolution over the 30 electrodes, $F_2 = 64$ separable filters, and dropout 0.5; it has 74{,}933 parameters. Two average-pooling steps (factors 4 and 8) reduce the 500 time samples to 15, and the flattened $64 \times 15 = 960$-dimensional vector before the output layer is the EEG feature. Two defects in the reference implementation---a weight-constraint hook that replaced a layer's output with its weights, and a trainer that left the model in evaluation mode after the first epoch---were fixed before any reported run (Chapter~\ref{chap:engineering_challenges}).

\textbf{Within-subject training.} Each encoder is trained separately for every participant on their 280 training trials, and the final epoch is kept; no epoch is chosen using test data. AST and ViT first train only the new output layer with the backbone frozen, then fine-tune all weights (AdamW; learning rate $5\times10^{-4}$ then $5\times10^{-6}$; batch size 8 for AST and 32 for ViT). EEGNet is trained from scratch with Adam at learning rate $10^{-5}$, batch size 32, for 350 epochs. The cross-subject variant of this training is described in Section~\ref{sec:cs_implementation}.

\section{Fusion Methods}

\subsection{Why Self-Attention over Three Tokens}
\label{sec:fusion_design_rationale}
Lee, Kim and Kim \cite{Lee2024MERCL} fuse three modalities with six directional cross-attention blocks, each letting one modality's sequence of tokens attend to another's. Here each encoder yields a single pooled vector per trial, so every modality is one token. Cross-attention from one single token to another reduces to a learned linear map, and six such maps add parameters without adding expressiveness. The fusion module therefore treats the three modality vectors as a three-token sequence and applies standard self-attention, in which every token attends to all three. Moving to sequence-level features and pairwise cross-attention would be the natural extension, but it requires re-extracting features for every fold and tuning a new architecture, and was not attempted (Chapter~\ref{chap:conclusion}).

\subsection{The Attention Module}
\texttt{TrimodalAttentionFusion} (Figure~\ref{fig:attention_architecture}) computes:
\begin{enumerate}
    \item a separate linear projection of each modality to a common width $D = 256$,
    \begin{equation}
        h_a = W_a x_a + b_a, \quad h_v = W_v x_v + b_v, \quad h_e = W_e x_e + b_e,
    \end{equation}
    with $x_a, x_v \in \mathbb{R}^{768}$ and $x_e \in \mathbb{R}^{960}$;
    \item the addition of a learned modality embedding, $u_m = h_m + E[m]$ with $E \in \mathbb{R}^{3\times256}$ initialised with standard deviation 0.02, so that the attention layers can tell the tokens apart;
    \item two transformer encoder layers over the sequence $[u_a; u_v; u_e]$ (8 heads, feed-forward width 1024, GELU, normalisation before each sub-layer, dropout 0.1), followed by layer normalisation;
    \item the mean of the three output tokens, $f = \tfrac{1}{3}(\tilde u_a + \tilde u_v + \tilde u_e)$;
    \item a two-layer classifier, $z = W_2\,\mathrm{Dropout}(\mathrm{GELU}(W_1 f + b_1)) + b_2$, giving five logits trained with cross-entropy.
\end{enumerate}
The module has 2{,}287{,}621 parameters. Besides the logits, it returns the three post-attention tokens and $f$.

With EEG absent, $x_e = 0$ and the EEG token becomes $b_e + E[e]$: a fixed, finite vector. The module therefore always produces valid output without EEG, and modality-dropout training (Section~\ref{sec:modality_dropout}) teaches it to rely on the other two tokens in that case.

\subsection{Concatenation Baseline}
\label{sec:concat_baseline}
To separate the value of attention from the value of learning a fusion at all, a multi-layer perceptron is trained on the concatenated features: $2{,}496 \rightarrow 512 \rightarrow 128 \rightarrow 5$ with GELU and dropout 0.1, 1{,}349{,}765 parameters, and the same training settings as the attention module.

\subsection{Naive Late Fusion}
\label{sec:naive_method}
The parameter-free baseline averages the three encoders' class probabilities and predicts the most probable class:
\begin{equation}
    \hat{y} = \arg\max_k \tfrac{1}{3}\big(\mathrm{softmax}(z_a) + \mathrm{softmax}(z_v) + \mathrm{softmax}(z_e)\big)_k .
\end{equation}
Because a confident modality contributes a peaked distribution, the average is implicitly weighted by confidence. A learned fusion method that cannot beat it has not justified its parameters.

\subsection{Modality Dropout}
\label{sec:modality_dropout}
Following Chumachenko et al.\ \cite{Chumachenko2022SelfAttention}, a second copy of the attention module is trained with softhard modality dropout. For each training sample, with probability 0.5, one of the three modalities chosen at random is set to zero and the remaining ones are scaled by $3/n_{\mathrm{active}}$ so that the input's expected magnitude does not change:
\begin{equation}
  \tilde{x}^{(m)} = \frac{3\, k_m}{\sum_{m'} k_{m'}}\, x^{(m)}, \qquad k_m \in \{0, 1\}.
\end{equation}
The model thus sees complete inputs about half the time and each two-modality combination about a sixth of the time, including the audio-visual combination a user without an EEG headset would provide. Accuracy with EEG set to zero at test time is the robustness measure. The Pre-Thesis~II report described this scheme incorrectly (Section~\ref{sec:p3_challenges}, C20).

\section{Coherence Analysis}
\label{sec:coherence_analysis}
The coherence analysis asks how often, and in which direction, the EEG classifier disagrees with an agreeing pair of audio and vision classifiers. A trial $t$ of participant $s$ counts as an event when
\begin{equation}
S(s,t)=1 \Longleftrightarrow
\hat{y}_{a}(s,t)=\hat{y}_{v}(s,t) \;\land\; \hat{y}_{e}(s,t)\neq\hat{y}_{a}(s,t) \;\land\; \max_k p_{e,k}(s,t)\geq0.5,
\end{equation}
that is, audio and vision agree, EEG predicts something else, and EEG gives its choice at least half the probability mass. Events are counted in a $5\times5$ matrix whose rows are the audio-visual class and columns the EEG class (Figure~\ref{fig:suppression_criteria}):
\begin{equation}
    M_{r,c}=\sum_{s}\sum_{t}\mathbf{1}\left[S(s,t)=1 \land \hat{y}_{a}(s,t)=r \land \hat{y}_{e}(s,t)=c\right].
\end{equation}

\begin{figure}[htbp]
\centering
\IfFileExists{images/fig_4_3_suppression_criteria.png}{\includegraphics[width=0.9\textwidth]{images/fig_4_3_suppression_criteria.png}}{\fbox{\parbox{0.86\textwidth}{\centering Missing image placeholder: \texttt{images/fig\_4\_3\_suppression\_criteria.png}.}}}
\caption{Criteria for a coherence event: audio and vision agree, EEG disagrees, and EEG is at least 50\% confident.}
\label{fig:suppression_criteria}
\end{figure}

A matrix built this way mixes two sources: genuine differences between what the participant showed and what their EEG reflects, and the EEG classifier's own mistakes. To separate them, each cell is compared with a null distribution. Within every participant and every cued class, EEG's (prediction, confidence) pairs are shuffled across trials 2{,}000 times while audio and vision stay fixed. This keeps every classifier's class-by-class error pattern exactly and destroys only the trial-level pairing between modalities, so a cell above the null reflects coupling that independent errors cannot produce. Two-sided permutation $p$-values are corrected with Holm's method over the 20 off-diagonal cells. The results are in Section~\ref{sec:audit_suppression}.

\section{Evaluation Protocols}
\label{sec:evaluation_protocols}

Four protocols are used, each answering a different question.

\textbf{Within-subject} (Chapter~\ref{chap:within}): encoders and heads are trained on one participant's 280 training trials and tested on their 120 test trials, averaged over 42 participants. This measures recognition of a person the system has already studied, and is the protocol of all previous fusion work on EAV.

\textbf{Cross-subject} (Chapter~\ref{chap:crosssubject}): five-fold cross-validation over participants, with encoders and heads retrained for every fold on the other participants and epochs chosen on three held-aside training participants. This measures recognition of a new person.

\textbf{Cross-subject with calibration} (Chapter~\ref{chap:calibration}): as above, but each participant's features are standardised with statistics from a short unlabelled recording of that participant. This measures recognition of a new user who provides a brief enrolment session.

\textbf{Cross-subject with labelled calibration} (Chapter~\ref{chap:calibration}): as above, with the enrolment clips labelled and used to fine-tune the fusion head.

In every protocol, the reported epoch of every trained model is chosen without looking at the data it is scored on. Statistical methods are described in Section~\ref{sec:statistical_analysis}.

\section{Implementation}

\subsection{Workflow and Storage}
\label{sec:path_configuration}
Code was written on machines without a usable GPU, versioned in the GitHub repository \texttt{shafinmuffinn/thesis\_p2}, and pulled into Google Colab sessions for training (Figure~\ref{fig:workflow}). Data, checkpoints, cached features, logits and result tables live on Google Drive, which Colab mounts. One module, \texttt{paths.py}, resolves every location from environment variables (\texttt{THESIS\_ROOT}, \texttt{EAV\_PICKLES}, \texttt{CHECKPOINTS}, \texttt{RESULTS}, \texttt{PRETRAINED}), set by the first cell of each Colab notebook or by the local run configuration, so no script contains a hard-coded path. Pre-trained model weights are cached on Drive so they are downloaded only once.

The per-modality logits needed by naive late fusion and the coherence analysis were not saved by the first within-subject rollout; they were regenerated afterwards from the saved encoder weights (\texttt{compute\_per\_modality\_logits.py}, Section~\ref{sec:c9}). The cross-subject pipeline saves features, logits and trained heads in the same pass.

\subsection{Epoch Budgets and Cost}
\label{sec:epoch_budget}
The EAV repository's default budgets (AST 10 frozen + 15 fine-tuning epochs; ViT 10 + 5) were reduced after a three-participant pilot. AST's training accuracy saturated within five fine-tuning epochs and further epochs did not improve test accuracy, so its budget became 5 + 5. The facial-emotion ViT starts close to the task and reached its best accuracy within two fine-tuning epochs, so its budget became 3 + 2. EEGNet, trained from scratch, kept 350 epochs. These choices were informed by the pilot participants' test curves; Section~\ref{sec:audit_selection} discusses this.
